# Site da Nunes Telecom

Este é um site estático. Todas as imagens ficam diretamente nesta pasta, ao lado de `index.html`; não há subpastas de imagens. Os caminhos relativos também funcionam quando o GitHub Pages publica o site sob o endereço `/nome-do-repositorio/`.

## Publicar pelo GitHub Pages

Extraia o ZIP e envie **todos os arquivos que estão nesta pasta** para a raiz do repositório (ou para `/docs` se essa for a pasta configurada no Pages). Mantenha juntos `index.html`, `servicos.html`, `script.js`, `style.css` e os arquivos de imagem. Em `Settings > Pages`, escolha o branch e a pasta que contêm `index.html`.

## Abrir no Windows

Dê dois cliques em `ABRIR-SITE.bat` ou abra `index.html` no navegador.

O site inclui explicações dos nove serviços e um carrossel que troca de imagem a cada cinco segundos, com controles para pausar e navegar manualmente.

O telefone, e-mail e área de atendimento foram mantidos a partir do site recebido; confirme se continuam corretos antes de publicar.
